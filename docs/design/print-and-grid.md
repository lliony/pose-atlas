# 打印、构图网格与图片优先卡片

三件事的落地说明：**打印尺寸跟随页面**、**卡片可以随时补照片改文案**、**屏幕上的照片可以叠相机式 3×3 网格**。

> 2026-10-21 更新：打印不再单独选卡片尺寸与比例。比例在页面工具栏选一次（3:4 / 4:3 / 9:16 / 16:9），打印按纸张平分平铺；正面与反面相邻成对，PDF 页序即「正、背」。

## 1. 打印版式

### 模型（`src/lib/print.ts`，纯函数、有测试）

```ts
fillLayout({ paper, orientation, ratio })
// → { paperW, paperH, cardW, cardH, cols, rows, perSheet, … }
```

- **纸张**：A5 / A4 / A3 / Letter，横竖各一套。
- **比例**：`3:4 / 4:3 / 9:16 / 16:9`，来自页面的 `data-card-ratio`，打印对话框里不再出现比例选项。
- **平铺**：以短边 **70mm** 为基准排出尽可能多的卡，再整体放大（最多 ×1.35）把纸面用满；纸太小装不下时先缩到放得下。剩余空隙由打印样式的 `space-evenly` 均分，四周与卡间一致。
- **安全边距**：横向 8.5mm、纵向 5mm。

常见组合：

| 纸张 | 比例 | 版面 | 单卡 | 每面 |
| --- | --- | --- | --- | --- |
| A4 横向 | 3:4 | 4×2 | 70×93.3mm | 8 |
| A4 横向 | 1:1 | 3×2 | 93.3×93.3mm | 6 |\n| A4 横向 | 2:3 | 4×2 | 66.7×100mm | 8 |\n| A4 横向 | 3:2 | 2×2 | 140×93.3mm | 4 |
| A4 横向 | 16:9 | 1×2 | 168×94.5mm | 2 |
| A4 横向 | 9:16 | 3×1 | 93.3×165.9mm | 3 |
| A5 竖放 | 9:16 | 1×1 | 94.5×168mm | 1 |

> 卡片高度有下限（84mm）：低于这个高度，背面五段笔记排两栏也放不下，所以横卡宁可少排几张。

### 渲染

`print.css` 全部由变量驱动：

```css
#print-root {
  --paper-w / --paper-h / --card-w / --card-h / --cols / --rows / --gap
  --card-fs: calc(min(var(--card-w), var(--card-h)) * 0.0271);
}
```

字号以**卡片短边**为锚点，卡内间距、栏高、字号都用 em，所以换纸张、换比例都不会串版。`@page` 的尺寸没法用变量，改成运行时注入一段 `@page { size: …mm …mm }`。

### 打印用缩略图

打印前把 `#print-root` 里每张图按长边 1600px 重绘成 JPEG（画布编码，不动屏幕上的原图），再参与文字预检与打印。示例 24 张卡、6 面的 PDF 从 **27.1MB 降到 5.5MB**，纸上分辨力约 190dpi。

### 双面翻转

`printSheets(items, edge, cols, rows)` 按行列泛化：

- 短边翻转 = 每行左右镜像 `row*cols + (cols-1-col)`
- 长边翻转 = 整张上下镜像 `(rows-1-row)*cols + col`

### 横卡布局

`4:3` / `16:9` 时卡片不是简单压扁：`#print-root[data-wide="on"]` 切到「图片左 58% / 文案右」的两栏，背面笔记自动分两栏，避免宽画幅被裁成一条。

### 文字放不下时

预检先让单张卡的笔记字号自动缩（最多 16%），仍放不下才拦下打印，并把原因钉在对话框底部、附「定位」按钮跳到那张卡。

## 2. 卡片再编辑

- 详情弹窗底部有 **编辑这张卡** / **＋ 添加照片**；后者打开编辑器并直接滚到上传区、聚焦文件选择框。
- 编辑器不再静默套用本地草稿：载入草稿时顶部出现「已恢复上次未保存的修改」，旁边一键「放弃草稿，改用已保存版本」。存储键为 `pose-draft-<userId>-<cardId>`，新建卡共用 `new`。
- 卡片右上角 ↗ 与翻面后的「编辑」保留，`aria-label` 完整。

## 3. 构图网格

- 工具栏的网格按钮，`aria-pressed`，状态存 `pose-atlas:grid`，写在 `body[data-grid]` 上。
- 纯 CSS 叠加：两条 `linear-gradient` + `background-size: 33.3333%`，任意尺寸照片框里都是 1px 线，`pointer-events: none` 不影响点击。
- 打印对话框另有「打印时叠构图网格」，默认关。

## 4. 打印设置持久化

`pose-atlas:print` 保存纸张、方向、翻转方式、网格四项；比例与卡片宽度来自页面，不重复保存。页面外观（比例 / 边框）另存 `pose-atlas:appearance`。

## 6. 图片比例：识别、提示与裁切

- **上传即识别**：`measureFile()` 用 `createImageBitmap` 读出 `width/height` 存进 `Photo`，卡片直接按这个比例显示；旧数据没有尺寸时由图鉴页探测后补齐（不写库）。
- **七个标准档**：`1:1 / 2:3 / 3:4 / 9:16`（竖）与 `3:2 / 4:3 / 16:9`（横），容差 5%。不属于任何一档的图在编辑器里显式提示，卡片右下角标「非标准比例」，比例筛选里不会出现。
- **裁切**：编辑器给非标准图提供「居中裁切并替换」，选目标比例后按中心裁切、重新上传为新的 JPEG，并写回 `width/height`。裁切是破坏性的（替换当前图），原图不保留。
- **分组打印**：每张图按自己的比例归组，同组同版面，正面紧跟反面。
## 7. 编辑器里的两处便利

- **预览按原图比例完整显示**：`.editor-preview` 用图片真实宽高做 aspect-ratio，内部 `object-fit: contain`，2:3 的竖图不会再被裁成方形。
- **AI 帮我填满**：编辑器把当前图压到 1600px、转 JPEG，连同**当前分类名与已写标题**一起 POST `/api/ai/draft`；系统提示词按卡片真实约束写死——标题 ≤28 字、五段笔记各 ≤80 字（打印预检的硬上限）、性别只能 女性/男性/多人、风格只能取那 8 个、标签 ≤4 个，并要求写机位/焦段/构图/光位这类可执行细节。返回的 JSON 经 `normalizeDraft()` 按同样上限截断、去重、过滤非法值，再合并进表单（**已有内容不覆盖**）。\n- 404 的含义：本地 AI 服务没启动，或启动的是改动前的旧进程（旧进程没有 `/api/ai/draft`）。重启 `npm run dev:ai` 即可。
## 8. 多模型

`createConfigStore` 在旧版单配置之外新增 `pose-ai-profiles:<user>`：`{version:1, profiles:[{id,name,baseUrl,apiKey,model}], recommend, draft}`。

- 系统设置里可增删改多个档案，并分别指定「推荐用」「填充用」；选「系统默认」表示不走个人配置。
- `store.useFor("recommend" | "draft")` 返回该功能实际使用的配置，推荐浮窗与编辑器各自取自己的那份，服务端协议不变（仍是 `{kind:"personal", config}` 或 `{kind:"default"}`）。
- 旧数据（`pose-ai-config:<user>`）会显示成一个叫「默认模型」的档案，不写回磁盘；清除后不残留。
- 未勾选「记住本机」时档案只在本次页面有效，界面会明确提示。
