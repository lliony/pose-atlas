# 暖色档案 Amber Archive · Pose Atlas 配色方案

> 一句话：明度关系不动，只把色相整体转向暖区——A 暖纸 + 陶土橙、B 白墙 + 陶土红、C 深褐 + 琥珀，三版共用同一套语义角色，但**中性色温、强调色相、选中表达**各不相同。
>
> 三版：**A 纸本**（暖纸底 / 填充）/ **B 白墙**（纯白底 / 描边）/ **C 暗房**（深褐底 / 提亮）。样张见 `warm-palette.png`、`warm-palette-white.png`、`warm-palette-dark.png`。

| | A · 纸本 | B · 白墙 | C · 暗房 |
| --- | --- | --- | --- |
| 底色 | `#F7F1E7` 暖纸 | `#FFFFFF` 纯白 | `#17120E` 深褐 |
| 中性色 | 暖褐 `#6E5A47` | 中性灰 `#6B6763` | 沙褐 `#B39C83` |
| 主强调 | `#A5512B` 陶土橙（H19） | `#AA4530` 陶土红（H10） | `#D08A4E` 琥珀（H28） |
| 按钮文字 | 白 `#FFFCF6` | 白 `#FFFFFF` | 深褐 `#17120E` |
| 选中表达 | 橙雾填充 + 深陶土字 | 1px 红描边 + 红字 | 暗琥珀填充 + 浅琥珀字 |
| 结构靠 | 三层纸色差 + 阴影辅助 | 单层白 + 1px 细线 | 四级提亮 + 1px 暖线 |
| 彩色面积 | 可达 15% | ≤ 5% | ≤ 8% |
| 气质 | 档案、可触摸、适合打印 | 展签、克制、照片优先 | 暗房、沉浸、照片发光 |

---

## 1. 共用原则

| 判断 | 落到的设计决策 |
| --- | --- |
| 照片必须是主角 | 所有界面色降彩度，只留 accent 一支高彩度色。C 方案里照片是最亮的一块。 |
| 档案感 = 克制 + 精确 | 一屏只有一处实心强调色；其余一律描边/文字按钮。 |
| 暖不等于黄 | A 的底色只暖一档；B 干脆不用暖底（中性灰 4% 色度）；C 用褐黑而不是纯黑。 |
| 文字不用纯黑也不纯白 | 浅色版用 `#2A2119` / `#191817`，暗色版用 `#F2E7D8`。黑白两端都不走极端。 |
| 温度要么统一、要么对立 | A / C 全部颜色 H 落在 19°–40°，是"一个温度"；B 反过来——中性无彩 + 一支 H10 的陶土红，靠对立而不是统一。 |
| 换方案不换语义 | 只映射 6 个角色（paper / surface / line / ink / accent / tint），强调色按对比度重新选值，不逐色取反。 |

## 3. 方案 B · 白墙（纯白底 · 描边结构）

和 A 的区别不只是"纸变白"：**中性色去掉了黄，强调色更红，选中态从填充改成描边**。三处一起换，才看得出是两个方案。

| Token | Hex | 用途 |
| --- | --- | --- |
| `paper` / `surface` | `#FFFFFF` | 底色与卡面同值 |
| `sunken` | `#F5F4F2` | 侧栏、状态条、表头（色度仅 13% 的近中性带） |
| `line` / `line-strong` | `#E6E3DE` / `#D4D0C9` | 分隔线 / 卡片描边（B 的结构几乎全靠这根线） |
| `ink` | `#191817` | 主文本 17.7:1（近中性黑，不带红） |
| `ink-soft` | `#454240` | 小标题、图标 10.0:1 |
| `muted` | `#6B6763` | 说明文字 5.6:1（色度 4%，与 A 的 `#6E5A47` 一眼可分） |
| `faint` | `#9E9A94` | 装饰性微文案 |
| `accent` | `#AA4530` | 主 CTA（H10，比 A 更红更沉；白字 5.8:1） |
| `accent-hover` | `#8A3223` | hover / 浅底彩字 7.2:1 |
| `accent-tint` | `#F9EEEA` | 只作 ≤5% 面积的提示底，**不用于选中态** |
| `brass` | `#A98A5E` | 铜线：1px 细线、编号，3.2:1 不承载正文 |

**白墙的三条规则**

1. **中性不带褐**：说明文字用 `#6B6763`（色度 4%）。一旦混进 A 的 `#6E5A47`，白墙立刻变回纸，两案就分不开了。
2. **选中态用描边，不用填充**：白底 + `1px #AA4530` + 红字。填充 pill 是 A 的语言，B 一用就同质化。
3. **彩色面积压到 5% 以下**：`accent-tint` 只出现在提示块；卡片不加阴影，只留 `1px #E6E3DE`——阴影会把"墙"变回"纸"。

## 4. 方案 C · 暗房（深褐底）

### 基底与层级

| Token | Hex | 相对 paper | 用途 |
| --- | --- | --- | --- |
| `sunken` | `#120E0A` | 1.03× | 状态条、表头（往内收） |
| `paper` | `#17120E` | 1.00 | 页面底色（不是 `#000`，带 3% 红 / 2% 黄） |
| `surface` | `#241B14` | 1.10× | 卡片、弹窗 |
| `raised` | `#2E2218` | 1.19× | hover、下拉、卡片页脚 |
| `line` / `line-strong` | `#3A2E24` / `#55402F` | — | 分隔线 / 卡片描边 |

### 文字

| Token | Hex | on paper | 用途 |
| --- | --- | --- | --- |
| `ink` | `#F2E7D8` | 15.2:1 AAA | 主文本（暖白，不用 `#FFF`） |
| `ink-soft` | `#D9C7B0` | 11.3:1 AAA | 小标题、图标 |
| `muted` | `#B39C83` | 7.1:1 AAA | 说明文字、元信息 |
| `faint` | `#94806A` | 4.9:1 AA | 仅 ≥14px 装饰性微文案 |

### 强调与状态

| Token | Hex | 对比度 | 用途 |
| --- | --- | --- | --- |
| `accent` | `#D08A4E` | 深褐字 6.6:1 | 主 CTA（**亮底 + 深字**，暗色按钮的标准做法） |
| `accent-hover` | `#E3A268` | on paper 8.5:1 | hover / 暗底琥珀文字 |
| `accent-tint` | `#3B2A1C` | 承载 `#E3A268` 6.3:1 | 选中 pill、标签底 |
| `brass` | `#C79A5C` | 7.3:1 | 暗底上黄铜反而达标，可作编号刻线 |
| `olive` | `#93A766` | 7.1:1 | 成功 / 已保存 |
| `amber` | `#D39954` | 7.5:1 | 警示 |
| `brick` | `#D9705A` | 5.7:1 | 危险 / 删除 |
| `focus` | `2px #E3A268` | — | 键盘焦点环，offset 2px |

### 暗色四条

1. **分层靠提亮，不靠阴影**：阴影在深底上几乎不可见，靠 `1.03 / 1.10 / 1.19` 三级提亮 + 1px 暖线，只做一样界面会糊成一片。
2. **强调色升两档**：`#A5512B → #D08A4E`。浅色的深绿/陶土在暗底会显浊。
3. **别用纯白正文**：`#F2E7D8` 才是暗底上的白；`#FFFFFF` 会"发光"，长时间读刺眼。
4. **遮罩要更重**：`#0B0806CC`（80%），浅色模式的 40–60% 在暗底不足以隔离背景。

## 6. 怎么选

- **A 纸本**：长时间浏览、打印/导出是主要出口、想要"档案册"的重量感。
- **B 白墙**：会和别的白底产品并排、要极干净的展签感、希望两套方案一眼能分开（中性灰 + 陶土红 + 描边）。
- **C 暗房**：作品集/展厅场景、夜间使用为主、希望照片"自己发光"。
- **A + C 成对**（推荐做双主题）：语义角色完全对应，切主题只换 token；B 是另一种设计语言（描边而非填充），适合作为独立版本。

## 7. 用法边界

**共用**

- 一屏只有一个实心强调色按钮，其余用描边或文字按钮。
- 徽标、编号用 `brass`；浅色版不承载正文，暗色版可用但只做刻线。
- 选中 pill：A / C 用 `accent-tint` 底 + `accent-hover` 字；**B 用白底 + 1px `accent` 边 + `accent` 字**，不用填充。
- 图片不加暖滤镜：暖色交给底色、线条和文字。

**各自**

| | 关键动作 | 禁忌 |
| --- | --- | --- |
| A | 三层纸色差分层，阴影只作辅助 | 纯白卡面（在暖纸上发蓝）、底色过黄 |
| B | 1px 细线撑结构，彩色面积 ≤5%，选中用描边 | 混入 A 的暖褐中性、橙色填充 pill、大面积 `#F9EEEA`、加卡片阴影 |
| C | 四级提亮 + 暖线分层；琥珀只做点 | 纯黑底、纯白正文、用阴影分层、大面积琥珀 |

---

## 8. 落地顺序

1. 选 A / B / C，或 A+C 做双主题；替换 6 个基础语义 token。
2. 全局搜索硬编码色（`#F0F1EB`、`#DFE7DD`、`#CCD3C7`、`#416B51`、`#E8E8E0`、`#14291F`…），按第 5 节映射替换。
3. 只保留主 CTA 为实心强调色；暗色版记得把按钮文字改成深褐，别沿用白字。
4. 用第 2/3/4 节的对比度数值直接验收，浅色与暗色分别测。
