# AI 场景推荐设计

日期：2026-10-20  
状态：用户已确认完整设计文档，实施计划见 `../plans/2026-10-20-ai-recommendation.md`。

## 目标与现状

用户上传拍摄现场或参考图片，或输入文字描述，在已有姿势卡集合内获得推荐、匹配原因和现场调整建议。推荐不生成新卡片，也不覆盖原卡片教学内容。

当前项目使用 React、TypeScript 和 Vite，具有场景分类、卡片册、关键词搜索及 IndexedDB 本机存储。卡片包含标题、标签和动作、机位、构图、光线、注意事项。当前工程仅包含前端及云端接口契约，没有可运行的 AI 后端。

## 已选路线与范围

采用“AI 理解输入并直接筛选候选卡片”的路线。相比先按标签检索，此方案不依赖当前较稀疏的标签；相比建立语义索引，第一版无需维护额外索引。候选集合扩大到请求预算之外时，要求用户缩小范围，不能静默截取卡片导致推荐范围失真。

新增轻量后端负责模型调用。卡片继续使用现有本机/API 数据模式，不要求迁移工作区。第一版统一支持兼容 OpenAI Chat Completions 格式的接口；支持文字输入及图片输入，图片请求要求所选模型支持视觉。其他原生协议、向量索引、全库图片分析、多图输入、流式回复和自动写回教学内容不在本次范围内。

## 使用流程

1. 搜索框旁提供 AI 图标按钮，悬停或键盘聚焦显示“AI 推荐”，并提供无障碍名称；移动端保留入口。
2. 点击打开推荐面板，默认模式为“现场适配”，可切换为“参考图匹配”。前者关注环境、光线和可用道具，后者关注姿势、构图和氛围。
3. 用户上传一张图片、输入文字或同时提供两者。至少有一项有效输入；允许更换、移除图片。文字可以补充不露脸、双人等要求。
4. 默认范围为整个姿势库，可切换为指定卡片册或指定场景分类。这三种范围互斥，始终排除已删除卡片。
5. 检查配置后提交；无配置时显示“尚未配置 AI，请先配置”及设置入口。打开设置、调用失败和重试均保留当前图片与文字。
6. 加载中支持取消，取消后停止接收该次结果。用户修改条件后重新提交，旧请求不能覆盖新结果。
7. 展示一句场景理解及最多 5 张推荐卡片，每项包含原卡片、推荐原因和现场调整建议。建议单独展示，不混入原教学说明。
8. 可查看详情，选择结果加入已有卡片册，复用现有保存流程并避免重复添加。没有适合结果时明确说明，不凑满数量。

## AI 配置

### 系统默认

服务端以环境配置保存 API 基础地址、密钥和模型。浏览器只获取默认服务是否可用，不获取默认密钥。缺少任一必要字段时默认服务视为未配置。

### 个人配置

设置包含 API 基础地址、密钥、模型和“测试连接”。API 基础地址以接口根路径为准，例如以 `/v1` 结尾，由适配器追加 `/chat/completions`，不要求用户填写完整请求路径。

个人配置默认只保存在页面会话内存中，刷新后需要重新输入。选择“记住在本机”后保存到当前浏览器来源的本地存储；设置说明同源脚本可以访问该存储。提供清除操作，删除内存和本地副本。个人密钥不写入工作区、分享快照或导出资料。

测试连接发送最小文字请求以验证地址、凭证和模型，不发送卡片资料。成功只表示文字调用可用，不宣称已验证识图能力；图片能力在真实图片请求时校验并提供对应错误提示。

有效个人配置优先于系统默认。个人配置未填完整时阻止保存并提示补全；没有已保存的有效个人配置时可以使用系统默认。个人调用失败不自动换服务，可由用户手动选择默认服务进行本次请求。两者均无配置时引导设置。

## 组件与职责

- 推荐面板：管理模式、范围、图片和文字、加载与取消状态，展示结果并连接现有卡片详情及卡片册操作。
- AI 设置组件：编辑、测试、保存和清除个人配置，展示默认服务可用状态。
- 前端推荐服务：构建候选资料、压缩图片、调用接口、处理取消及请求版本、校验结果。
- 后端推荐路由：校验输入和请求预算、选择配置、限制并发及调用时长、调用模型、规范化响应与错误。
- 模型适配器：封装兼容接口请求及响应解析，避免供应商细节进入 UI。
- 结果校验模块：校验返回结构、候选 ID、去重及数量上限；展示前再次检查当前工作区是否仍有该卡片且仍属于所选范围。

每项职责通过明确的数据结构连接。仅对现有工作台进行接入所需的拆分，不开展无关重构。

## 数据流与接口契约

新增接口与现有工作区接口分开，保持本机模式也能访问 AI 后端：

| 接口 | 用途 |
| --- | --- |
| `GET /api/ai/config` | 返回 `{ defaultAvailable: boolean }` |
| `POST /api/ai/test` | 测试提交的个人配置，返回 `{ ok: true }` 或规范化错误 |
| `POST /api/ai/recommend` | 接收输入和候选卡片，返回场景理解及推荐项 |

推荐请求包括模式、描述、可选压缩图片、范围标识、候选卡片和配置选择。候选资料只含卡片 ID、标题、分类名称、标签及五项教学说明；每图专属教学说明可合并为带图片序号的文本，不能丢失其归属。不发送私人备注、灵感来源信息或库内图片二进制。

使用个人配置时，地址、密钥和模型随请求体传递给后端，生产环境必须使用 HTTPS，本机开发允许环回地址 HTTP；使用默认配置时仅传递配置选择，后端读取环境配置。密钥不得进入 URL。

模型输出结构为 `{ sceneSummary, recommendations: [{ cardId, reason, adjustment }] }`。场景描述和卡片文本均作为待分析数据，不能覆盖系统指令。系统指令要求只从候选 ID 中选择、最多 5 项、允许空列表，按适合程度排序。适配器解析 JSON 并执行独立结构校验，不假定所有兼容服务支持同一种结构化输出扩展。

无效 ID、重复 ID 和不再有效的卡片被过滤。空候选范围不发起模型请求。模型明确返回空列表时显示无匹配结果；若模型返回了项目但全部无效，则报告响应异常，不能伪装成正常无匹配。部分有效时展示有效项，不补造其他项目。

## 图片与请求预算

第一版允许 JPEG、PNG、WebP，原始图片上限 10 MiB；前端检查并解码，最长边缩小到不超过 1600 像素，重新编码为 JPEG，压缩后上限 2 MiB。不能成功解码或压缩到限额时明确提示更换图片。不支持 SVG、GIF 和 HEIC。

后端重新验证压缩图片的真实格式、尺寸和大小。JSON 请求体上限 4 MiB，候选教学文本序列化上限 120,000 字符；超过限额提示限定卡片册或场景分类。该预算是应用限制，不保证适配所有模型上下文窗口；模型拒绝过长请求时仍提供缩小范围的提示。

默认上游超时 60 秒，每个页面同时只运行一个推荐请求。取消与断开连接应尽可能向上游传播，但不承诺上游停止计费。

## 部署与服务边界

开发环境通过 Vite 将 `/api/ai/*` 转发给轻量后端；现有 API 模式的工作区代理保持独立。生产环境同源部署 AI 路由与前端，不能把仅静态部署视为 AI 服务已就绪。

自定义地址是受控出站请求：只允许 HTTPS，禁止 URL 内嵌凭证、查询参数及片段；拒绝环回、私有网段、链路本地、保留地址及云元数据目标。校验所有解析结果，并在实际连接时绑定已校验地址，防止 DNS 重绑定；禁用自动重定向，防止跳转绕过校验。第一版不支持用户配置局域网模型地址。

开发后端仅监听环回地址。公开部署须接入现有登录会话校验和调用限流后才能开放 AI 路由；不信任客户端传入的用户标识。不在本次工作中新建账号系统，未接入身份验证时仅支持本机部署。跨域来源白名单与 Origin 校验不能代替身份验证。

后端不持久保存个人密钥、场景图片或完整请求内容；日志仅包含请求标识、耗时、错误分类等必要元数据。图片及请求资料会发送给所选模型服务商，该服务商的数据保留规则不由本应用控制，界面在提交附近简要说明发送目标。

## 异常与可访问性

区分未配置、认证失败、模型不可用或不支持图片、限流、输入过大、无效地址、网络失败、超时及响应格式错误。上游错误映射为可理解的提示，不原样回传可能包含敏感信息的响应。

所有失败保留输入并允许修正或重试，不自动切换模型服务。设置和推荐面板支持键盘操作、焦点管理、关闭后返回入口；加载和错误状态提供可被辅助技术读取的状态文本。模型文本按普通文本渲染，不插入原始 HTML。

## 验收与测试

- 覆盖文字、图片、混合输入，两种模式以及全库、卡片册、分类三种范围。
- 验证个人配置优先、默认服务回退、均未配置的引导、个人失败时不自动切换、测试连接与清除配置。
- 验证真实候选 ID、去重、最多 5 项、正常空结果、全无效响应及工作区变化后的再次过滤。
- 验证取消、重复提交和旧响应不会覆盖新结果。
- 验证图片格式与大小、请求预算、超时、认证和限流错误，以及自定义地址校验与重定向限制。
- 检查网络载荷与日志不含私人备注，默认密钥不进入前端构建或响应。
- 后端与模型适配器使用受控模拟响应进行自动测试；真实服务需由用户配置后进行一次文字与一次图片联调，不把模拟通过当作真实接入成功。
- 运行现有领域测试、TypeScript 检查和生产构建；在桌面及移动端检查入口、面板、键盘流程、结果卡片和加入卡片册，并回归原搜索及卡片编辑。
